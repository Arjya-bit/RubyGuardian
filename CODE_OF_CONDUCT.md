# Code of Conduct

## Our Pledge

We as members, contributors, and leaders pledge to make participation in our
community a harassment-free experience for everyone, and to use this security
research framework responsibly and ethically.

## Ethical Use Standards

### Acceptable Use

- Academic research in controlled environments
- Authorized penetration testing with written consent
- Security tool development and validation
- CTF competitions and training exercises
- Improving detection and defense capabilities

### Unacceptable Use

- Attacking systems without explicit authorization
- Distributing malware derived from this framework
- Using techniques against production systems
- Selling or weaponizing PoC code
- Any activity that violates applicable laws

## Enforcement

Instances of abusive, unethical, or otherwise unacceptable behavior may be
reported to the project maintainers. All complaints will be reviewed and
investigated promptly and fairly.

## Attribution

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.0, with additional clauses specific to security research software.
