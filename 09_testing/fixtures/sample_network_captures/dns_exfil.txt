== Detection Indicators ==

HIGH CONFIDENCE indicators:
- DNS query rate: 18.8 queries/sec (baseline: 0.2 queries/sec) [+9300%]
- Subdomain label entropy: 5.8 bits/byte (normal DNS: 3.2 bits/byte)
- Base32/Base64 character distribution in subdomain labels
- Sequential numbering pattern in subdomain structure
- All queries to single non-standard external nameserver
- All responses are NXDOMAIN (data channel, not resolution)
- Query names exceed 100 characters average (normal: ~25 characters)
- UDP only to external IP (no corresponding TCP/HTTPS)

MEDIUM CONFIDENCE indicators:
- Queries use a single registered domain (exfil.example.com)
- Subdomain depth of 4+ levels (chunk.seq.fileid.exfil.example.com)
- No corresponding A record lookups for normal application domains
- Burst pattern: 18 queries/sec for 45 seconds then stops
- Source process (ruby) normally makes 0 direct DNS queries

LOW CONFIDENCE indicators:
- Unusual DNS query timing (evenly spaced at ~53ms intervals)
- Query sizes consistently near maximum label length (63 chars)
- No AAAA, MX, or TXT queries (only A records used as cover)
